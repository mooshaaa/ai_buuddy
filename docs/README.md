# Спецификации AI-buddy (SDD)

Здесь описано поведение AI-функций прототипа: что система обязана делать, чего не делает намеренно и как это проверяется.
Спецификации фиксируют поведение реализованных функций и служат источником требований для дальнейшей разработки
(согласование отгула наставником, новые инструменты, подключение реальных сервисов). Каждый критерий приёмки привязан к тесту в `backend/tests/`.

| Файл | Содержание |
|---|---|
| [00-overview.md](00-overview.md) | цель, роли, архитектура, оркестратор, память диалога, устойчивость к сбоям модели |
| [02-knowledge-base.md](02-knowledge-base.md) | ответы строго по базе знаний с источниками |
| [04-access-control.md](04-access-control.md) | права доступа по ролям |
| [05-absence-action.md](05-absence-action.md) | реальное действие: заявка на отгул через сервис |
| [06-metrics.md](06-metrics.md) | метрики пользы и проверка эффекта |

Отчёт о покрытии кода тестами: [coverage-report.txt](coverage-report.txt).

Формат каждого файла: цель, вход и выход, правила, границы, критерии приёмки, трассировка «критерий → тест».
