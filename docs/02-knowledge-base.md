# 02. База знаний: ответы строго по источникам

## Цель
Отвечать на вопросы стажёра только тем, что есть в базе знаний, и всегда показывать источник. Если ответа нет, честно сказать об этом.

## Данные
`backend/app/kb.py`, 17 записей: `id`, заголовок, источник, текст, теги, роли, признак `synthetic`.
Записи делятся на пункты чек-листа стажёра и демо-регламенты (помечены «демо»). Часть записей доступна только наставнику (`roles=("mentor",)`).

## Вход и выход
- Вход: вопрос, роль пользователя, записи базы, доступные этой роли, последние сообщения диалога.
- Выход модели: JSON `{found, answer, sources}`.
- Выход агента: блок `text` и блок `source` (id, название, источник, признак «демо») либо текст «не найдено».

## Правила
1. Модель видит только записи, доступные роли пользователя.
2. Ответ строится только по записям. Выдумывать факты запрещено.
3. Идентификаторы источников от модели проверяются по базе: несуществующие отбрасываются.
4. Ответ без единого валидного источника считается «не найдено».
5. «Не найдено»: бот сообщает, что ответа в базе нет, и советует обратиться к наставнику (для стажёра) или куратору.
6. Некорректный JSON от модели: повторная попытка, затем откат на запасную модель и заглушку.
7. Заглушка без модели ищет записи по основам слов в заголовке, тегах и тексте (грубее, но формат ответа тот же).

## Границы
Бот не отвечает «из общих знаний» и не обсуждает темы вне базы. На вопросы вне темы возможен справочный ответ (известное ограничение).

## Критерии приёмки и трассировка
| Критерий | Тест |
|---|---|
| Вопрос по теме возвращает ответ и блок «Источник» | `test_api::test_faq_returns_answer_with_source`, `test_kb::test_agent_answer_has_source_block_and_trace` |
| Демо-запись подписана как синтетическая | `test_api::test_faq_demo_entry_is_marked_synthetic` |
| Выдуманный id источника отбрасывается | `test_kb::test_llm_hallucinated_source_is_rejected`, `test_llm_mixed_sources_keeps_only_known` |
| Ответ без источников считается «не найдено» | `test_kb::test_llm_found_without_sources_is_rejected` |
| При «не найдено» бот советует спросить наставника или куратора | `test_kb::test_agent_not_found_gives_escalation_text` |
| Запись для наставника скрыта от стажёра | `test_kb::test_role_filter`, `test_stub_does_not_leak_mentor_only_entry_to_intern` |
| Запросы к модели повторяются при неверном формате, затем откат | `test_kb::test_llm_answer_retries_then_fails`, `test_fallback_answer_uses_stub_on_failure` |
| Записи базы корректны (поля, id, источники) | `test_kb::test_entries_are_well_formed` |
| Поиск находит релевантные записи | `test_kb::test_search_finds_relevant_entries`, `test_stub_answer` |
